1. Order

Order berisi pesanan dari buyer yang menjadi dasar untuk proses selanjutnya. Masing-masing order memiliki nomor SPI (Surat Pesanan Internal).

Informasi yang dapat dilihat

  • Order number
  • Buyer
  • Order date
  • Order quantity
  • Ship date
  • Informasi order lainnya

Contoh format order number / SPI: 2B/2026/HBI/1821. Assortment digunakan untuk melihat pembagian order berdasarkan style, color, size, dan quantity.

Destination menunjukkan lokasi tujuan pengiriman, sedangkan Ship date menunjukkan tanggal barang harus dikirim.
