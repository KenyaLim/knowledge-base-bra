Documentation

Bahasa Indonesia

1. Order

Order berisi pesanan dari buyer yang menjadi dasar untuk proses selanjutnya. Setiap order memiliki nomor SPI (Surat Pesanan Internal).

Order Entry Detail

Menu ini berisi informasi utama mengenai order:

  • Order number
  • Buyer
  • Order date
  • Order quantity
  • Ship date
  • Informasi order lainnya

Contoh format order number / SPI: 2B/2026/HBI/1821.

  • 2B menunjukkan unit.
  • 2026 menunjukkan tahun order.
  • HBI menunjukkan buyer.
  • 1821 menunjukkan nomor urut order.

Assortment digunakan untuk melihat pembagian order berdasarkan style, color, size, dan quantity.

PO Buyer berisi purchase order dari buyer dan menjadi referensi untuk mengetahui produk yang harus diproduksi.

Destination menunjukkan lokasi tujuan pengiriman. Buyer dan destination tidak selalu sama, misalnya buyer Inggris tetapi barang dikirim ke Brazil.

Ship date adalah tanggal barang harus dikirim sesuai permintaan buyer. Style menunjukkan model garmen, color menunjukkan warna, dan size menunjukkan ukuran produk.

English

1. Order

An order contains a buyer's request and becomes the basis for the following processes. Each order has an SPI number (Internal Order Letter).

Order Entry Detail

This menu contains the main order information:

  • Order number, buyer, order date, order quantity, ship date, and other order information.

Example order number / SPI: 2B/2026/HBI/1821. 2B is the unit, 2026 is the order year, HBI is the buyer, and 1821 is the sequence number.

Assortment shows order distribution by style, color, size, and quantity. Buyer PO is the buyer's purchase order and the reference for the products to be produced.

Destination is the shipping location and may differ from the buyer's location. Ship date is the requested shipping date. Style, color, and size identify the garment model, color, and measurement.

Bahasa Indonesia

Modul lanjutan

Setelah Order, proses berlanjut ke MRP, Purchase, Inventory, Cutting, Sewing, Packing, Inventory FG, Shipment, Reporting, dan Web Report.

English

Following modules

After Order, the process continues to MRP, Purchase, Inventory, Cutting, Sewing, Packing, Finished Goods Inventory, Shipment, Reporting, and Web Report.
