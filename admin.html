NAVIGATION MANAGEMENT

Navigation

Kelola parent dan child navbar tanpa mengubah file HTML.

Guide pengelolaan navbar

  1. Sync existing navbar: gunakan terlebih dahulu untuk mengambil struktur STAGE, PROMAN, module, child, dan icon dari navbar saat ini.
  2. Add: kosongkan editor untuk membuat item baru. Pilih area STAGE/PROMAN, tipe kategori atau laman, lalu pilih parent.
  3. Kategori: digunakan sebagai root atau module. Kategori tidak memiliki Page key dan URL.
  4. Laman HTML: wajib memiliki parent module, Page key, dan URL. Laman menjadi child yang tampil sebagai link di navbar.
  5. Pilih icon: klik salah satu icon Phosphor. Icon terpilih akan tampil di preview dan tersimpan saat menekan Save navigation.
  6. Edit: klik tombol Edit pada item di daftar, ubah data, lalu tekan Save navigation.
  7. Urutan: tarik item dengan drag-and-drop ke posisi item lain dalam parent yang sama. Urutan tersimpan otomatis.
  8. Delete: klik Delete pada item yang dipilih. Menghapus kategori juga menghapus child di bawahnya.
  9. Published: item hanya tampil di navbar user jika status Published aktif.

Navigation structure

Parent adalah kategori. Child adalah tautan ke halaman HTML.
